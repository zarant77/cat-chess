# Cat Chess Roadmap

## MVP 1 — Server + Web

- Create game by 6-symbol code
- Join game by code
- Issue player secrets
- Store game state
- Submit moves
- Render board in web client

## MVP 2 — Android client

- Add native C Android client into `apps/android`
- Store local player secret
- Fetch game state
- Submit moves
- Render board and pieces

## MVP 3 — Notifications

- Optional push notifications after opponent move
- Keep the game playable without notifications
